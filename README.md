# Linux For DevOps

This repository contains Linux notes and practice material for DevOps Engineers.

The following topics are covered as part of this course and documentation.

- Linux Fundamentals
- Linux Architecture
- Linux File System
- Linux User Management
- Linux File Management
- VI Editor Shortcuts
- File Permissions
- Process Management
- Monitoring
- Networking
- Disk Management
- Shell Scripting Basics

Please refer to the folders in this repository to learn each topic step by step.
