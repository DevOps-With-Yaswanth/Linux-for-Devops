# 🐧 Linux Distributions

Linux distributions (distros) are different versions of Linux that package the Linux kernel with various software, utilities, desktop environments, and package managers.

Each Linux distribution is designed for different use cases such as:
- personal use
- servers
- cloud computing
- security
- DevOps
- containers

---

# 📌 Popular Linux Distributions

## 🟠 Ubuntu

Ubuntu is one of the most beginner-friendly Linux distributions.

Features:
- easy to use
- large community support
- widely used in cloud and DevOps

Common Usage:
- servers
- cloud computing
- DevOps
- development

Website:
- https://ubuntu.com

---

## 🔴 Red Hat Enterprise Linux (RHEL)

RHEL is an enterprise-grade Linux distribution developed by Red Hat.

Features:
- stability
- security
- enterprise support

Common Usage:
- enterprise servers
- banking systems
- production environments

Website:
- https://www.redhat.com

---

## 🟢 CentOS / Rocky Linux / AlmaLinux

CentOS was previously a popular free alternative to RHEL.

After CentOS changes, Rocky Linux and AlmaLinux became popular replacements.

Features:
- enterprise stability
- RHEL compatibility

Common Usage:
- enterprise servers
- DevOps labs
- hosting

---

## 🔵 Debian

Debian is one of the oldest and most stable Linux distributions.

Features:
- highly stable
- secure
- lightweight

Common Usage:
- servers
- backend systems

Website:
- https://www.debian.org

---

## 🟣 Fedora

Fedora is a community-driven Linux distribution sponsored by Red Hat.

Features:
- latest Linux technologies
- developer friendly

Common Usage:
- development
- testing
- learning Linux

Website:
- https://getfedora.org

---

## ⚫ Kali Linux

Kali Linux is designed for cybersecurity and penetration testing.

Features:
- security tools
- penetration testing tools
- ethical hacking utilities

Common Usage:
- cybersecurity
- penetration testing

Website:
- https://www.kali.org

---

## 🟦 Alpine Linux

Alpine Linux is a lightweight and security-focused Linux distribution.

Features:
- very small size
- minimal resource usage
- fast

Common Usage:
- Docker containers
- Kubernetes environments
