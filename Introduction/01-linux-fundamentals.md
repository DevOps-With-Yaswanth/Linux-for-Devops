
# 🐧 Linux Fundamentals

Linux is one of the most widely used operating systems in the world.

Most modern technologies like:
- DevOps
- Cloud Computing
- Docker
- Kubernetes
- AWS
- CI/CD

run on Linux servers.

Learning Linux is the first step toward becoming a successful DevOps Engineer.

---

# 📌 What is Linux?

Linux is:
- an open-source operating system
- secure
- stable
- lightweight
- highly scalable

Linux was created by **Linus Torvalds** in 1991.

# 📖 Components of Linux

## 1️⃣ Kernel
The kernel is the core part of Linux.

Responsibilities:
- memory management
- process management
- hardware communication
- device management

---

## 2️⃣ Shell
The shell acts as an interface between the user and the kernel.

Examples:
- bash
- sh
- zsh

---

## 3️⃣ File System
Linux organizes everything as files and directories.

Examples:
- `/home`
- `/etc`
- `/var`
- `/tmp`

---

## 4️⃣ Hardware
Physical resources like:
- CPU
- RAM
- Disk
- Network devices

---

- Better resource utilization

- High scalability

---

## 🔒 Security and Reliability

- Strong user permission model
- Less vulnerable to malware
- Frequent security updates
- High system stability
